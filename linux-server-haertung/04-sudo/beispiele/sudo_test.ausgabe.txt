## Version
Sudo version 1.9.15p5

## 1. Regeldatei nach Least Privilege (nur zwei Befehle, mit Protokoll)
$ visudo -cf /etc/sudoers.d/t14-test
/etc/sudoers.d/t14-test: parsed OK

## 2. Absichtlich kaputte Datei: visudo meldet den Fehler, bevor sudo kaputtgeht
$ visudo -cf /etc/sudoers.d/t14-kaputt
/etc/sudoers.d/t14-kaputt:1:40: syntax error
t14gast ALL=(root) NOPASSWD /usr/bin/id
                                       ^
Rückgabewert: 1

## 4. Erlaubter und verweigerter Aufruf (als t14ops, ohne Passwortabfrage: sudo -n)
$ sudo -n /usr/bin/id
uid=0(root) gid=0(root) groups=0(root)
$ sudo -n /usr/bin/cat /etc/shadow
sudo: a password is required
$ sudo -n -u root /bin/bash   (Shell wäre zu mächtig)
sudo: a password is required

## 5. Als t14gast (keine Regel)
