Übung **01.1** (Priorität 1). Geschätzte Zeit: 5 bis 6 Stunden (Schätzung; Lehrplan: 8 UE zu 45 Minuten = 6 Stunden).

| Datei | Zweck |
|---|---|
| `01.1-haertungskonzept-und-baselines.md` | Die Übung mit Aufgaben, Kontrollfragen und Musterlösung |

| `baseline_vergleich.py` | Vergleicht eine exportierte Sicherheitsvorlage (INF-Format, erfundene Beispieldaten) mit einer eigenen Baseline-Tabelle (CSV). |
| `lauf.sh` | Vergleicht die Beispiel-Sicherheitsvorlage mit der Baseline-Tabelle (Python 3). |
| `sicherheit.inf` | Skript |
| `beispiele/lauf.ausgabe.txt` | Echte Ausgabe des Laufs von `lauf` |
