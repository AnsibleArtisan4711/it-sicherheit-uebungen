| Datei | Zweck |

| `kennzahlen.py` | Berechnet Kennzahlen aus dem Befundverlauf (CSV, frei erfunden): mittlere Behebungsdauer (MTTR) je Priorität, Fristeinhaltung, offene und überfällige Befunde. |
| `lauf.sh` | Prüft das Beispiel-Ausnahmeregister und berechnet Kennzahlen (Python 3). |
| `beispiele/lauf.ausgabe.txt` | Echte Ausgabe des Laufs von `lauf` |
